ARCHITECTURAL DESIGN.

4.1 Written Architecture

The system follows a client-side layered architecture:

Presentation Layer – HTML pages

Styling Layer – CSS & Bootstrap

Logic Layer – JavaScript files

Data Layer (Simulated) – JavaScript objects & arrays

There is no backend or database.
