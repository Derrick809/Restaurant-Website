# Derry's Restaurant — Landing Page

This is a responsive landing page for the Restaurant Website project. It uses the frontend-only architecture described in the documentation (HTML, Bootstrap, CSS, and JavaScript).

Quick preview

1. Open `index.html` in your browser (double-click or serve with a static server).

If you want a simple HTTP server (Python 3):

```bash
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

Files added:
- `index.html` — landing page
- `css/styles.css` — page styles
- `js/script.js` — small script to populate featured dishes and filter buttons

Notes
- Images are referenced from `asset/Restaurant Images/` using URL-encoded spaces.
- This site is frontend-only (no backend). The admin and ordering features referenced in the docs are simulated in the main project.
